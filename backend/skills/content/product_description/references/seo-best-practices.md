# SEO Best Practices for E-commerce Product Descriptions

## Keyword Research

### Long-tail Keywords
- Use 3-5 word phrases instead of single words
- Example: "wireless bluetooth earbuds noise cancelling" vs "earbuds"
- Tools: Google Keyword Planner, Ubersuggest, AnswerThePublic

### Keyword Placement
1. **Product Title** - Most important keyword first
2. **First 100 characters** - Include primary keyword
3. **Bullet points** - Natural keyword variations
4. **Description** - Secondary keywords
5. **Meta description** - Primary keyword + CTA

## On-Page SEO

### Title Optimization
- Length: 50-60 characters (Google displays ~60)
- Format: `Product Name | Key Benefit — Brand`
- Include primary keyword
- Add modifiers: "Best", "Top", "Premium", "2026"

### Meta Description
- Length: 150-160 characters
- Include primary keyword
- Add CTA: "Shop now", "Free shipping", "Limited time"
- Make it compelling - this is your ad copy

### URL Structure
- Use hyphens, not underscores
- Keep it short and descriptive
- Include primary keyword
- Example: `/wireless-bluetooth-earbuds-noise-cancelling`

## Content Guidelines

### Word Count
- Minimum: 300 words for product pages
- Optimal: 500-1000 words for competitive niches
- Don't sacrifice quality for length

### Keyword Density
- Primary keyword: 1-2% of total words
- Don't stuff keywords - write naturally
- Use synonyms and variations

### Readability
- Short paragraphs (2-3 sentences)
- Bullet points for features/benefits
- Subheadings (H2, H3) for structure
- Active voice, simple language
- Flesch Reading Ease: 60-70 (8th grade level)

## E-commerce Specific

### Product Schema Markup
```json
{
  "@context": "https://schema.org/",
  "@type": "Product",
  "name": "Product Name",
  "description": "Product description",
  "brand": "Brand Name",
  "offers": {
    "@type": "Offer",
    "price": "99.99",
    "priceCurrency": "USD"
  }
}
```

### Image Optimization
- Alt text with keywords
- File names: `product-name-keyword.jpg`
- Compress images (WebP format)
- Multiple angles + lifestyle shots

### User-Generated Content
- Customer reviews (keyword-rich)
- Q&A sections
- User photos
- Ratings (rich snippets)

## Platform-Specific SEO

### Shopee
- Title: 60 characters max
- Use all 5 image slots
- Enable Q&A
- Encourage reviews

### Lazada
- Title: 255 characters max
- Rich product descriptions
- Video content
- Flash sales boost visibility

### Amazon
- Backend search terms (250 bytes)
- A+ Content for brand registry
- Bullet points: 200 characters each
- Enhanced Brand Content

## Common Mistakes to Avoid

❌ Keyword stuffing
❌ Duplicate content across products
❌ Ignoring mobile optimization
❌ Missing alt text on images
❌ Slow page load times
❌ No internal linking
❌ Ignoring user intent
❌ Generic product descriptions

## SEO Checklist

- [ ] Primary keyword in title
- [ ] Primary keyword in first 100 characters
- [ ] 3-5 long-tail keywords naturally placed
- [ ] Meta description with CTA
- [ ] Alt text on all images
- [ ] Schema markup implemented
- [ ] Mobile-friendly
- [ ] Page load time < 3 seconds
- [ ] Internal links to related products
- [ ] Customer reviews enabled
- [ ] Social sharing buttons
- [ ] Breadcrumb navigation
